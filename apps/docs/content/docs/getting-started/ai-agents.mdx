---
title: Set up AI agents
description: Point coding agents at the foundation and install the recommended skills and tooling.
---

The foundation is built to be understood by AI coding agents, not just people. A few minutes of
setup makes an agent follow the conventions by default.

## 1. Add an AGENTS.md

Give your app an `AGENTS.md` at the repo root that states the stack, points to the foundation docs,
and sets the rules (prefer shadcn, use tokens not hardcoded values, app-specific components stay
local). Use the foundation's [AGENTS overview](/docs/reference/agents) as the template.

## 2. Install the recommended skills

Skills give agents accurate, current guidance for each part of the stack. Install with the
[skills CLI](https://www.skills.sh):

```bash
npx skills add <owner/repo>
```

See [AI and agents](/docs/ai) for the full grouped list (frontend, backend, docs).

## 3. Enable the agent tooling

The team recommends a small set of optimizations: RTK, loop-engineering
(`CKGrafico/loop-task` + `CKGrafico/opencode-onboard`), and the humanizer skill for prose. See
[AI and agents](/docs/ai#tooling-and-workflow).

## 4. Regenerate docs from code

Architecture and design docs are generated by the `opencode-onboard` skills
(`ob-make-architecture`, `ob-make-design`) so they stay honest as the code changes. Re-run them
instead of hand-editing large sections.
