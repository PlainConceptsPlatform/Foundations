---
title: Quickstart
description: Install the theme and components and get a themed app running in three steps.
---

This is the fastest path onto the foundation for a new or existing Next.js app. It matches the
[theme package README](https://github.com/PlainConceptsPlatform/Foundations/blob/main/packages/theme/README.md),
which stays the source of truth for the install steps.

<Callout type="info">
  Both packages are public on npm. There is no registry configuration and no access token to set up.
</Callout>

<Steps>

<Step>

### Install

<Tabs groupId="package-manager" persist items={["pnpm", "npm", "yarn", "bun"]}>

```bash tab="pnpm"
pnpm add @plainconceptsplatform/ui-theme @plainconceptsplatform/ui-components tailwindcss
```

```bash tab="npm"
npm install @plainconceptsplatform/ui-theme @plainconceptsplatform/ui-components tailwindcss
```

```bash tab="yarn"
yarn add @plainconceptsplatform/ui-theme @plainconceptsplatform/ui-components tailwindcss
```

```bash tab="bun"
bun add @plainconceptsplatform/ui-theme @plainconceptsplatform/ui-components tailwindcss
```

</Tabs>

</Step>

<Step>

### Initialize

```bash
npx @plainconceptsplatform/ui-theme@latest init
```

This copies `components.json`, adds the theme import to your global stylesheet, and shows you how to
wire the Outfit font in your root layout.

</Step>

<Step>

### Add shadcn components

```bash
npx shadcn@latest add button card dialog
```

They inherit the theme with no extra work, and you do not need to edit the generated source: the
theme neutralises the `shadow-*` utilities shadcn ships with, so upstream components already look
like a Platform app.

</Step>

</Steps>
