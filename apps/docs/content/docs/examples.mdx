## Planned example screens

- **Employees list**: table (TanStack Table), filters, status tags, pagination.
- **Employee detail**: header, tabbed sections, related data.
- **Settings form**: react-hook-form + zod, inline validation, loading and success states.

Each screen must cover loading, empty, and error states, and be verified at the `sm`, `md`, and
`lg` breakpoints.
