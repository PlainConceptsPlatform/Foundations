## Installation

```bash
pnpm add @plainconceptsplatform/ui-components
```

You also need the shadcn primitives the component delegates to (Table, Button,
DropdownMenu) plus an icon library. The package itself is headless - it accepts
*slots* for every piece of UI, so you control the look and feel.

```bash
npx shadcn@latest add table button dropdown-menu
pnpm add lucide-react          # or @tabler/icons-react, heroicons, etc.
```

## Usage

The package component is render-delegate: instead of importing icon libraries,
i18n, or shadcn directly, it accepts **slots** (Button, Table, DropdownMenu),
**texts** (localised strings), and **icons** (your icon library).

Each app creates a thin wrapper that wires up its own primitives once:

```tsx
"use client";

import {
  DataTable as PackageDataTable,
  type DataTableSlots,
  type DataTableTexts,
  type DataTableIcons,
} from "@plainconceptsplatform/ui-components";
import { ArrowUp, ArrowDown, ArrowUpDown, ChevronDown, ChevronRight, Columns3, X } from "lucide-react";

import { Button } from "@/components/ui/button";
import {
  DropdownMenu, DropdownMenuCheckboxItem, DropdownMenuContent,
  DropdownMenuLabel, DropdownMenuSeparator, DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";
import {
  Table, TableBody, TableCell, TableHead, TableHeader, TableRow,
} from "@/components/ui/table";

const slots: DataTableSlots = {
  Table, TableHeader, TableBody, TableRow, TableHead, TableCell,
  Button, DropdownMenu, DropdownMenuTrigger, DropdownMenuContent,
  DropdownMenuLabel, DropdownMenuSeparator, DropdownMenuCheckboxItem,
};

const texts: DataTableTexts = {
  dragToGroup: "Drag a column header here to group",
  groupedBy: "Grouped by",
  stopGrouping: (label) => `Stop grouping ${label}`,
  clear: "Clear",
  columnsCount: (v, t) => `Columns (${v}/${t})`,
  toggleColumns: "Toggle columns",
  noRecords: "No records",
  dragReorderOrGroup: "Drag to reorder or group",
  dragReorder: "Drag to reorder",
  columnGrouping: "Column grouping",
};

const icons: DataTableIcons = {
  IconSortAscending: ({ className }) => <ArrowUp className={className} />,
  IconSortDescending: ({ className }) => <ArrowDown className={className} />,
  IconArrowsSort: ({ className }) => <ArrowUpDown className={className} />,
  IconChevronRight: ({ size }) => <ChevronRight size={size} />,
  IconChevronDown: ({ size }) => <ChevronDown size={size} />,
  IconColumns: ({ className }) => <Columns3 className={className} />,
  IconX: ({ className }) => <X className={className} />,
};

export function DataTable<T>(props: Omit<Parameters<typeof PackageDataTable<T>>[0], "slots" | "texts" | "icons">) {
  return <PackageDataTable<T> {...props} slots={slots} texts={texts} icons={icons} />;
}
```

Then use the wrapper just like any other component:

```tsx
import { DataTable } from "@/components/ui/data-table";
import type { DataTableColumn } from "@plainconceptsplatform/ui-components";

type App = { id: string; name: string; stack: string; status: "Active" | "Deprecated" };

const apps: App[] = [
  { id: "1", name: "Numa", stack: "React", status: "Active" },
  { id: "2", name: "Docs", stack: "Next.js", status: "Active" },
  { id: "3", name: "Legacy", stack: ".NET", status: "Deprecated" },
];

const columns: DataTableColumn<App>[] = [
  {
    key: "name",
    label: "App",
    render: (r) => <span className="font-medium">{r.name}</span>,
    sortValue: (r) => r.name,
    groupValue: (r) => r.stack,
  },
  {
    key: "stack",
    label: "Stack",
    render: (r) => r.stack,
    sortValue: (r) => r.stack,
  },
  {
    key: "status",
    label: "Status",
    render: (r) => <Badge variant={r.status === "Active" ? "default" : "secondary"}>{r.status}</Badge>,
    sortValue: (r) => r.status,
  },
];

<DataTable tableId="my-table" rows={apps} rowKey={(r) => r.id} columns={columns} defaultGroupBy={["stack"]} />
```

## Features

- **Click-to-sort** - click any sortable column header to cycle asc / desc / off
- **Drag-to-group** - drag a column header onto the grouping bar to create collapsible groups (multi-level)
- **Column reorder** - drag column headers left/right to reorder
- **Show/hide columns** - use the Columns dropdown to toggle visibility; state persists in localStorage
- **Persistent state** - column order, visibility, and grouping are saved per `tableId` in localStorage
- **Group aggregates** - pass `groupAgg` on a column to show totals/counts in group header rows

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tableId` | `string` | - | Stable id for localStorage persistence |
| `rows` | `T[]` | - | Data rows (server-paged, sorted/grouped client-side) |
| `rowKey` | `(row: T) => string` | - | Unique key per row |
| `columns` | `DataTableColumn<T>[]` | - | Column definitions |
| `slots` | `DataTableSlots` | - | UI primitives (Button, Table, DropdownMenu) |
| `texts` | `DataTableTexts` | - | Localised strings |
| `icons` | `DataTableIcons` | - | Icon components |
| `defaultSort` | `SortState` | - | Initial sort `{ by, order }` |
| `defaultGroupBy` | `string[]` | `[]` | Initial grouping column keys |
| `enableGrouping` | `boolean` | `true` | Show the drag-to-group bar |
| `onRowClick` | `(row: T) => void` | - | Row click handler |
| `emptyMessage` | `ReactNode` | `"No records"` | Empty state content |
