## Installation

Typography is a documentation pattern rather than a shadcn registry component:
there is no `npx shadcn@latest add typography`. It demonstrates how plain HTML
text elements render against the shared tokens (Outfit family, semantic colors,
radius). No UI source is added; the prose below uses semantic Tailwind utilities.
